# 蜀山之王：贡嘎绝地 (King of Shu Mountain: Gongga Wilderness)

一个硬核的高海拔徒步生存游戏，模拟在中国四川贡嘎环线的朝圣之旅。

## 🎮 游戏特色

- **山脉森林美学设计**：参考 cyberhiking.cn 风格，清爽的界面设计
- **四维度生存系统**：健康、体力、体温、理智
- **真实地理模拟**：海拔2500-4830米的垂直自然带变化
- **四季系统**：春季、夏季、秋季、冬季，各有不同的挑战
- **野生动物互动**：大熊猫、雪豹、羚牛等真实物种遭遇
- **道德选择**：是否帮助其他徒步者，影响精神状态
- **精神崩溃机制**：理智值低时出现视觉扭曲效果

## 🚀 如何开始

1. **打开游戏文件**

   在浏览器中双击打开 `Mount-Gongga-Survival-Game.html` 文件

2. **装备采购**

   使用5000元预算购买装备（注意重量限制）

3. **开始朝圣**

   踏上环绕贡嘎山的徒步旅程

## 🎯 游戏目标

- **生还**：到达山顶并返回
- **精神成长**：在高海拔环境中找到内心的平静
- **最终评分**：根据你的生存状态和精神状态获得S-A-B-C等级评价

## 🎭 核心机制

### 精神状态（Sanity）
- 低于30%时游戏界面会颤抖
- 事件描述会出现扭曲
- 影响你的选择和判断

### 生存数值
- **体温(Warmth)**：高原失温防护，归零=危险
- **理智(Sanity)**：心理健康，影响游戏视觉
- **体力(Stamina)**：行动消耗，影响移动能力
- **含氧量(Oxygen)**：4000m 后血氧模拟，过低导致理智暴降。

### 遭遇系统
- 随机野生动物遭遇
- 其他徒步者的故事
- 天气变化影响
- 海拔高度相关的挑战

## 🛠️ 技术特色
- **单文件游戏**：纯HTML+JavaScript+Tailwind CSS
- **模块化架构**：清晰的状态管理、事件系统、渲染器分离
- **响应式设计**：适配桌面和移动端
- **平滑动画**：状态变化和用户交互
- **测试模式**：可快速进入游戏核心内容

## 🎪 开发说明

### 测试模式
点击页面左下角的"测试模式"按钮即可跳过季节选择和装备采购，直接进入游戏核心内容，便于快速测试游戏功能。

### 文件结构
```
Mount-Gongga-Survival-Game.html    # 主游戏文件（单文件解决方案）
```

### 游戏架构
- `GameEngine`: 主引擎模块
- `EquipmentShop`: 装备商店系统
- `EventSystem`: 遭遇事件系统
- `ScenarioManager`: 场景管理器
- `EndingSystem`: 结局系统
- `StateManager`: 状态管理器
